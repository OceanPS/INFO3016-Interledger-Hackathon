# INFO3016-Interledger-Hackathon

This repository is the the 2026 Interledger Hackathon at Western Sydney University.

It is an general AI assistant to help international students manage and more importantly understand the currency exchange, the purchasing power multiplier, and then set up an Interledger payment transaction.
