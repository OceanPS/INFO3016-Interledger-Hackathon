# Money Transfer UI Mockup

A four-page responsive HTML/CSS/JavaScript recreation of the supplied mockups.

## Pages

1. `index.html` — choose destination and amount
2. `payment-details.html` — choose recipient, amount and source currency
3. `delivery.html` — choose a delivery method
4. `review.html` — review the transfer

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

The pages pass transfer data through URL query parameters, so no server or build step is required.
